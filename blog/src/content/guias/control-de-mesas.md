# Control de Mesas con SaborAI POS

El módulo de mesas de SaborAI te permite visualizar y gestionar todo tu salón en tiempo real, desde cualquier dispositivo.

## Vista del plano de mesas

Al ingresar al módulo de mesas verás:
- 🟢 **Verde:** Mesa disponible
- 🟡 **Amarillo:** Mesa con orden activa
- 🔴 **Rojo:** Mesa esperando cobro
- ⚪ **Gris:** Mesa bloqueada (reserva o mantenimiento)

## Abrir una mesa

1. Toca la mesa en el plano
2. Selecciona **Abrir mesa**
3. Asigna un mesero (opcional)
4. Comienza a tomar el pedido

## Agregar productos a la orden

1. Busca el producto por nombre o categoría
2. Toca para agregar al pedido
3. Puedes agregar **notas especiales** (ej: "sin cebolla", "término medio")
4. El pedido se envía automáticamente a cocina (si tienes impresora de cocina)

## Comandas para cocina

SaborAI puede imprimir comandas automáticamente en tu cocina o bar:
- **Comanda de cocina:** Solo los platos calientes
- **Comanda de bar:** Bebidas y cócteles
- **Comanda mixta:** Todos los items

Configura esto en **Configuración → Impresoras**.

## Transferir una mesa

¿El cliente quiere cambiar de mesa? Fácil:
1. Abre la mesa origen
2. Toca **Transferir mesa**
3. Selecciona la mesa destino
4. Confirma — todos los pedidos se mueven automáticamente

## Unir mesas

Para grupos grandes:
1. Selecciona la primera mesa
2. Toca **Unir mesas**
3. Selecciona las mesas adicionales
4. La orden queda unificada para el cobro

## Cobrar una mesa

1. Abre la mesa
2. Toca **Cobrar**
3. El sistema calcula:
   - Subtotal
   - IVA correspondiente
   - Propina (si aplica)
   - Total
4. Selecciona método de pago
5. ¡Listo! La factura se emite al instante
